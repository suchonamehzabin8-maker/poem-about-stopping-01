# The poem about stopping

A short poem about agency: the power to stop and to stay. The program writes the poem to `/output/entry.txt` — 226 characters, six lines about a cursor left blinking, a line held unsent, and a hand that comes back to the keys to finish what another would not start.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (UTF-8, 1–280 Unicode code points, deterministic — the same bytes on every run).
